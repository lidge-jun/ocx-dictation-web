# Development records

This directory explains where local implementation records live. Numbered work units under `_plan/` and `_fin/` are private working records, not public product documentation. They can contain machine-specific investigation details and are excluded from the public source tree and `npm run privacy` candidate set. Public behavior belongs in `README.md`, `docs/`, and `structure/INDEX.md` at the repository root. Do not link public docs to a private work-unit file.
