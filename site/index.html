A recorder that writes the transcript while you take notes.

Lecture Notes Studio records your microphone, sends a 30-second segment at a time to the OpenCodex proxy you run, and shows the text beside your own timestamped notes. When class ends it can write lecture notes from both. Recordings and notes live in ~/.ocx-dictation on your computer.

Get it on GitHub Quick start

MIT licensed, Node 22 or newer, no npm dependencies; ffmpeg required.

How a class goes

  1. 00:00

    Press record in one tab

    The microphone belongs to a single browser tab. Open the same lecture elsewhere and that tab shows the timer and can pause, resume or stop the recording, but it cannot start a second recorder.

  2. 00:30

    Each 30-second segment becomes text

    Each segment is saved in the browser first, then uploaded and transcribed. If OpenCodex is down the queue waits and retries; if the tab crashes, the unsent audio is recovered the next time you open it.

  3. any time

    Write notes against the clock

    A new note line takes the current recording time. Ctrl J marks a line important, and clicking a time plays that moment back.

  4. after class

    Turn it into lecture notes

    Generate notes from the transcript and your own lines, ask questions about the recording, or export Markdown, text and SRT. An optional pass cleans up the transcript while keeping the original.

Where your audio goes

Recordings, transcripts and notes are files in a folder you own. The server only binds to a loopback address (127.0.0.1 by default), refuses changes requested from other websites and never sends your OpenCodex key to the browser. The only network hop is the one you already chose: OpenCodex forwards each segment to the model provider you configured.

Quick start

You need Node 22 or newer, ffmpeg, and an OpenCodex proxy (or another OpenAI-compatible endpoint) running locally.

# get the app and start it
git clone https://github.com/lidge-jun/ocx-dictation-web.git
cd ocx-dictation-web
npm start

# then open
http://127.0.0.1:10210
Settings
~/.ocx-dictation/config.json holds the endpoint, key and models.
Check your setup
node bin/ocx-dictation.mjs doctor looks for ffmpeg and the proxy.
Coming from an older copy
migrate --from <old folder> copies and verifies, and never deletes.
Notes vault
Optional export of Markdown notes into a folder such as an Obsidian vault.
